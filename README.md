Student Finance Tracker is a Web aplication designed to help students record their expenses,monitor their spending, and manage their  budgets.

the project was built using HTML ,CSS, and JavaScript.

Features

.Expense management :Add,edit,and delete expenses.
.Search:Find expenses using regular expressions.
.Input Validation: Chech expense information before saving.
.Budget management:Set a budget Cap and monitor monthly spending.
.Currency concertion:View amounts in supported currencies using configurable exchange rates.
.Data storage:Save expense in the browser
.JSON export and import: Download a backup of expenses and settings and restore it later.
.Responsive design: Use the application on different screen sizes.

Project Structure

.index.html---Provides the structure of the application.
.styles/mainn.cs----Controls the appearance and responsive layout
scripts/storage.js — Saves and loads application data.

scripts/validation.js — Validates expenses and search patterns.
.script/main.js---Connects the javascript modules
.scripts/storage.js---Saves and loads
scripts/transactions.js — Manages expenses and search.

scripts/budget.js - Handles budget settings and spending warnings.


scripts/currency.js — Formats and converts currency amounts.

scripts/import-export.js — Imports and exports JSON backups.

How to Run the project

Clone or download this repository.

Open the project folder in Visual Studio Code.

Open index.html using a local web server, such as the VS Code Live Server extension.

Start adding and managing expenses in the application

Data and Privacy

The application stores its data in the browser's Local Storage. Export a JSON backup to keep a separate copy of your expenses and settings.

Importing a backup replaces the existing expenses and settings after confirmation.

Learning Objectives

This project provides practice with JavaScript modules, form validation, regular expressions, browser storage, JSON data, and responsive web design.

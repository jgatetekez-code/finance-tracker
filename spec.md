# Student Finance Tracker: Spec (M1)

## Purpose
A web app that helps a student record their spending, search it with regex, and see stats and a spending cap.

## Wireframes
- Mobile: wireframe-mobile.png
- Desktop: wireframe-desktop.png

## Data model
- id: unique id of the record
- description: what the money was spent on
- amount: how much was spent
- category: type of expense
- date: date of the expense (YYYY-MM-DD)
- createdAt: when it was added
- updatedAt: when it was last changed

## Accessibility plan
- Skip-to-content link
- Every input has a label
- Visible focus styles
- Works with keyboard only
- Errors announced with aria-live
- Good color contrast
